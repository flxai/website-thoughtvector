3. newsa6e192fecc0

PyTorch developers have released a patch to resolve a specific indexing error within the forward automatic differentiation diagnostic path. This fix addresses a flaw where the fast-mode diagnostic path could select the wrong tensor or trigger an index error instead of a proper gradcheck error. The problem occurred when non-differentiable inputs or integer outputs appeared early in the sequence, causing the slow-mode error reporter to reuse incorrect indices. To solve this, the patch maps the fast-mode input index back to the original input tuple and recomputes the selected output within the correct indexing domain. This technical update does not break backward compatibility and was verified through a series of successful tests on CPU. The developers noted that they used ChatGPT to assist in drafting the technical summary and test notes for this release, though the fix itself targets the diagnostic path rather than normal gradcheck computation.
